room's `WorldPosition` (sample: room at x −152 + item local 17 ⇒ world
−135, inside the room's tiles), `LocalRotation` is degrees.

widening beyond the three GameItem classes at implementation.

The sample record resolves end-to-end: pathId `522383310774550334` →

## §7 Coordinates and units — which space each datum lives in

| Datum | Source | Space | Units / convention |
|---|---|---|---|
| `WorldBounds` | LevelConfig (28) | world | metres-like Unity units; box 400×400×32 centred origin |
| `SpawnPoint` | LevelConfig | world | (−66, 0, −24) |
| `PlotRecords[].Bounds` | LevelScenarioV2 | **world** | centre+extent (Unity `Bounds`) |
| `RoomRecords[].WorldPosition` | LevelScenarioV2 | **world** | position of the room's tile-grid origin |
| `RoomRecords[].Anchor`, `Tiles` bitmap | LevelScenarioV2 | **grid cells** | 2.0 world units/cell; row-major w×h 0/1 occupancy |
| `ItemRecords[].LocalPosition` / `LocalRotation` | LevelScenarioV2 | **room-local** world units / degrees CW | add owning room's WorldPosition for world coords |
| `DigSiteBounds`, `NavBounds`, build-bounds `_center/_size` | item stubs / scene components | **object-local** world units | footprint libraries only |
| `States.GraphRect.*` | config/unlockable payloads | **graph-editor UI pixels** | NOT geographic — exclude from anything map-shaped |
| `TerrainMap/ObjectMap/AttributeMap` | LevelScenarioV2 plot layers | **tile indices** | ints; semantics partially known (EPlotTileType for plot tiles; terrain-paint enums unverified, G7) |
| `EDBDoorLink.Position` | runtime ECS (code only) | **world** | float3; door entities exist at runtime, positions not shipped as data (G8) |
| locale term IDs | everywhere | n/a | signed int32 → I2 registry (piece-02 §2 mechanism, unchanged) |

Projection consequence for the site: one shared linear transform per
campus — `map_px = (world_xz − campus_min) × scale` — suffices for
plots, rooms, and items alike, because everything above shares the one
world frame; Leaflet simple-CRS in game-unit space works unchanged from
scout-001 §5.
