3,154 packed slots vs 6,789 catalogue Sprites ⇒ ~55% of sprites live

exporter needs both routes (crop-from-page AND standalone-texture
pass-through).

## §5 Web-export requirement spec inputs (formats/ladder/naming/provenance)

Inputs the Documentator should pin — each traced to a §2–§4 measurement:

- **Formats.** Primary **WebP** (lossy q≈80 + alpha for icons; lossless
  acceptable alternative — Pillow 12.3.0 WebP support verified in the
  pack venv this session, `features.check('webp')=True`). PNG as the
  zero-surprise fallback for ≤64 px flat glyphs if WebP artifacts show.
  **AVIF NOT-NOW**: no `pillow-avif-plugin` in the venv (checked);
  ffmpeg 7.1 exists on PATH as an emergency transcoder but adds a
  second encode stack for no measured benefit at icon sizes.
- **Ladder.** Ship ONE canonical asset per sprite at native resolution —
  median max-dim ≈233 px, only 29 referenced crops ≤64 px and just
  4 above 512 px (§3.4) — plus an optional derived thumbnail tier
  (~96/128 px) for dense grid views, which is meaningful now that
  sources are large enough to downscale honestly. No upscaling, ever;
  a fixed 16/32/64-only ladder would destroy the median crop. CSS owns
  presentation sizing.
- **Naming.** `{plane}/{subObjectName}.webp` where subObjectName is the
  game-canonical sprite name (unique enough: 2,158 referenced names,
  collisions handled by `{name}_{pathId}` suffix rule — same rule as
  stage-3 dump filenames). **Entity-slug naming is a LATER pure rename
  map, not the export key**: piece-02 proved slug fields 100% null and
  prefix-strip resolves 1/417, so slugs do not exist yet; blocking the
  media stage on slug generation would invert the dependency. Emit
  `media/index.jsonl` mapping `(kind, srcId, fieldPath) → subObjectName
  → file` so the frontend never hardcodes either key.
- **Provenance per exported asset (repo/data plane only** — AGENTS rule
  3 two-class rule; never user-facing): `buildId 20226581`, source
  bundle, sprite pathId + atlas page pathId, assetGUID, subObjectName,
  contentAxis (base/dlc-space/dlc-ghost), output sha256, encoder+
  version pin. User surfaces carry buildId + coverage scope only.
- **Determinism contract** (matches house stage discipline): inputs =
  `media-catalogue.jsonl`, `relinks/entity_asset_guid.jsonl`,
  `relinks/bridges/container_index.jsonl`,
  `addressables/catalog.json`; outputs = `extracted/media/{icons,…}/**`
  + `media/export-manifest.jsonl` + sha256 hash manifest; idempotent
  re-run byte-stable (fixed Pillow/WebP version pinned in
  EXTRACTION-LOG.md); missing-icon refs land in an exit-2 ledger
  (`_missing_icons.jsonl`: the 7 DLC3 names + anything newly dangling)
  rather than failing the stage.
- **Out of scope for this piece** (per [DR-2026-08-18-media-scope] and
  promptForDB #5): audio/video (carve-out), meshes/animations
  (catalogue-first), fonts, generative/site-chrome art (later #44
  imagegen pass — this piece is CLIENT-owned art only).
