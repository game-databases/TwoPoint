## Findings

### F1 MAJOR — The §5/item-4 stage-6 RELATIONS.md template delta is NOT in effect at HEAD (concurrent commit reverted it)

`7fa73fc` landed the ruled-in-scope generator edit: the
`_relations_lines` availability bullet became "REGENERATED at its
canonical path by stage 9 `locale-proof` … supersedes the piece-02 §R4
stage-5 ownership pin". Fifteen minutes later, `9c7439c` (piece-05 /
stage-10 CodeWriter sharing this file) rebuilt the region from a stale
buffer and **restored the superseded text** —
`git show 9c7439c -- tools/stage6_relink.py` deletes the stage-9 routing
sentence and re-adds "`locale_availability.jsonl` stays STAGE-5 SOLE
PROPERTY (piece-02 §R4 pin…)". At current HEAD the blob greps 0 for
"REGENERATED at its". Consequences: the next `relink` run regenerates
`extracted/RELATIONS.md` attributing sole ownership to stage 5,
contradicting the ratified amendment — precisely the stale-pin hazard
arbiter R6 warned turns agents into restorers of dead ownership — and a
scoped deliverable of this piece is absent from HEAD even though the
commit claiming it exists. Mitigations already visible: the working tree
holds an uncommitted re-application of the same delta, and piece-05's own
V-D1 paragraph coexists cleanly with it (different bullets). **Fix:** land
the two-bullet coexistence as a commit (stage-9 routing sentence + V-D1
paragraph), and add a suite leg asserting `_relations_lines` output names
`locale-proof` so the next shared-file rebased edit cannot silently
revert it again.

### F2 MAJOR — Config name-bearing denominator diverges from the spec pin (measured 2,613 vs F11/AC4's 2,627) with no DRIFT line and no governance record

Live measurement: `kinds.config.perLocale.*.nameBearingEntities ==
2,613` (ru rate 30.50 %, ja 18.45 % — the scout percentages indeed do not
reproduce). Spec F11 pins config name-bearing **2,627**, F13 states
"(rule yields 2,627)", and AC4 requires name-bearing counts to "equal F11
exactly". The reconciliation round re-based the client-gated oracle to
2,613 (`test_N`, comment: "not F11's stale seed") — the measurement is
honest and every other kind matches F11 exactly — but the divergence from
the written contract is **silent at every layer a verifier reads**: (a)
`SEEDS` contains no name-bearing members, so unlike every other pinned
figure this one never prints a `DRIFT:` line naming old→new; (b) the
emitted `CONFIG_NAME_ROLE_NOTE` documents only the scout *percentage*
mismatch, not the 2,627→2,613 denominator divergence from the spec's own
pin; (c) `grep -r '2613|2627' docs/` finds nothing — the doctrine lives
only in a test comment and an untracked-by-docs commit message. A
verifier running AC4-as-written fails against the artifact with no
emitted explanation. **Fix (any one suffices, first is cheapest):** add
name-bearing seeds to `SEEDS` + `drift.check` so fresh-wins prints
`DRIFT:`; and/or record the doctrine beside its siblings (a short
rulings/reviews note covering all five reconciliation rulings — see
Observation O1).

### F3 MINOR — Dead verdict branch in `measure_symbol_lines`

`tools/stage9_locale_proof.py:1059`: inside the symbol loop,
`verdict = "verified-with-drift-symbol-line-missing"` is assigned when a
token is not found, but the function unconditionally returns
`"verified"` on the next line — the computed value can never be emitted.
Behavior happens to match the pinned two-value enum
(`verified|skipped-no-dump.cs`), but if `dump.cs` exists yet none of the
four symbols are found, the artifact claims `verified` with four
`dumpCsLine: null` entries and nothing prints. Either drop the dead
assignment or convert it to a `Drift.check` line (enum stays clean, loss
still surfaces).

### F4 MINOR — L5 consumes an upstream that §4's input universe does not declare

`run()` reads `relinks/ui_link_coverage.jsonl` (optional, absence ⇒
bindings 0) to measure `localizeBindings`. That path is in neither §4's
enumerated upstream set, `REQUIRED_INPUTS`, nor `run_all.UPSTREAMS`. DAG
is safe (it is a declared stage-6 output) and the 11,312 seed guards it
via DRIFT, but the stage's declared input contract is incomplete — the
test-side comment calls it the "measured-OPTIONAL L5 substrate", the spec
and gate never do. Add it to the optional-input documentation (and, if
desired, UPSTREAMS-free optional handling mirroring the alias input's
pattern).

### F5 MINOR — AC6's programmatic cross-check weakened to an inequality

AC6 pins row count "== `locale_join_report.registryHits` deduplicated —
asserted programmatically". Measured reality: `registryHits` is the RAW
edge counter (10,964), not a deduplicated entity count, so the code
asserts `len(rows) == len(grouped)` (true by construction) plus
`resolved_seen (5,850) <= registryHits (10,964)`. Net effect: the load-
bearing guard for the 5,850 figure is the seed DRIFT check, not the
pinned equality. Honest (an equality against 10,964 would be wrong), but
the deviation from AC6's wording deserves a one-line comment at the check
site or an oracle-computed dedup comparison.

### F6 MINOR — Per-cell `inferred:true` keyed by kind, not by resolution path

`pass_l2` sets `inferred = bool(alias_map) and kind == "course"` on ALL
course cells whenever the alias input is present — including courses
whose effective name edge came from the client fieldPath rule, or none
(unresolved courses stay ledgered yet their cells still claim
inferred). Spec §L2: "`inferred:true` appears ONLY on course rows
computed through the optional alias input." Latent only today (alias
input absent on this corpus; fixture legs use a total table), but the
flag should ride the per-entity `name_edges[key]["source"] ==
"alias-input"` predicate instead of the kind test.

### F7 MINOR — Stale inline ownership comments survive in three HEAD modules

`tools/stage4_localisation.py:34` ("Stage 5 is the SOLE OWNER…"),
`tools/relink_util.py:11` and `:129` ("stage-5 SOLE property"), and
`tools/stage0_verify_client.py:38` still describe the pre-amendment
world. None were in this piece's scoped write set (only the RELATIONS.md
template line was), but they are the same hazard R6 routed doc
supersession marks for: an agent reading `relink_util`'s header could
"restore" stage-5 ownership in good faith. Route a one-line-each comment
update to the documentator sweep alongside piece-01 Rev 8 / piece-02
marks.

### Observation O1 (non-blocking) — The five reconciliation rulings have no home outside commit `0295df6`

All five are implemented and (except F2) commented at their code sites,
but no `docs/rulings/*` or `docs/reviews/*` record records them, and the
commit message subject ("interface reconciliation") does not name them.
Given this batch's demonstrated shared-tree race (F1 happened within 15
minutes), a short ruling note listing the five deviations from Rev-3-as-
written — equal-rerun baseline untouched; `residualIdenticalInDe`
generalization; fieldPath-then-dev probe; config 2613 doctrine; alias
beside-root — would make the next auditor's job tractable.
