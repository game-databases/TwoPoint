## 5. Defect list (numbered; fix order matters)

**D0 — TEST-BUG (hard crash, blocks the R10 obligation once D6 lands).**
`tests/test_runner.py:262` — `*conftest_tree_game(fx_stage5_full)`:
`conftest_tree_game` is defined nowhere (grep over `tests/` and pack root:
single occurrence, this call). Today the test dies earlier at the
clean-reference run (stage-5 KeyError), so the bug is latent; the moment
stage 5 works, the flagship interrupted-run convergence test dies with
NameError instead of running. Fix: `from conftest import tree_game` and
pass `[str(tree_game(fx_stage5_full))]`.

**D1 — TEST-DEFECT (over-pin; permanent red against a compliant impl).**
`tests/test_stage4.py:89-91` — the three "unambiguous shapes → pinned
labels" assertions. Spec §3 stage 4 defines compositionPolicy only as the
four-value enum "selected by this stage's deterministic classifier from
observed evidence", and §7 routes the semantics question back as "**not
pre-pinned**". The impl ladder (tools/stage4_localisation.py:161-182) is
deterministic, evidence-backed, and reaches all four values (I drove the
16-shape sweep grid directly: `english-only`, `english-over-base`,
`base-over-english`, `mixed` all occur), but it labels the test's first
shape `english-over-base` where the test demands `english-only` — both
readings are defensible, neither is spec-mandated. A test may not fail an
implementation over semantics the spec deliberately leaves open. Fix
(either): (a) relax the three equality pins to what §8 actually obliges —
return ∈ enum, repeat-call determinism, distinguishable inputs can yield
different labels, all-four-reachable sweep kept — or (b) take a one-line
arbiter/documentator amendment defining the four labels observably, then
restore the pins against it. Route (b)'s question to QUESTION-QUEUE
regardless: consumers are told to "read the field, never prose", which
only works once the labels mean something written down.

**D2 — COVERAGE GAP (loud-skip; two §8 stage-3 obligations unproven).**
`tests/test_stage3.py:105-135` (reconciliation) and `:140-178`
(completeness checker) skip because `RECONCILE_NAMES`/`MEDIA_COMPLETE_NAMES`
resolve nothing — the landed impl computes both inline inside
`tools/stage3_harvest_bundles.py:211-221` with no importable seam, and no
hostless black-box alternative exists (fixture bundles are deliberately
non-UnityFS, so stage 3 always exits 2 before reconciling anything real).
Fixer: either extract pure helpers in the impl
(`reconcile_counts(censuses, manifest_rows, catalogue_rows)` /
`check_carveout_completeness(censuses, catalogue_rows)`) — both tests are
already written against exactly those signatures and will bind — or fold
the fabricated-numbers assertions into the client-gated heavy leg, which
already re-proves them on real outputs.
