## 2. Findings

### F1 — CRITICAL — placement identity collapses at corpus scale: the composite fallback exhausts its legs, uniqueness is never re-asserted, and cross-artifact joins break silently

**Location:** `tools/stage7_maps.py` `apply_identity_demotions`/`_demote`
(~1290–1346) + `ScenarioWalk.make_item_row` (~1015–1078).

**Evidence (this seat's measurements over the committed real-tree
artifacts):**

- `rooms.jsonl`: **5,055 / 5,188** `uniqueId` values are composite strings
  (`"0@r100"`), because `RoomRecords[].UniqueID` is `0` on essentially all
  rooms of this corpus (MoonBase: 264/264) — the discriminator the M2
  identity law presumes does not exist in the data.
- `item_placements.jsonl`: **19,284 / 23,004** rows carry a composite
  `owningRoomId`.
- **1,775 placement identity groups are STILL duplicated after demotion**
  (family key `(scenarioName, recordFamily, owningRoomId, plotUniqueId,
  itemIndex)`), worst group **46 rows** sharing one identity, e.g.
  `('LevelScenarioV2_All_Buildings','room','0@r0@p-2687913266509620906',
  None, 0) ×46`. Mechanism: the placement composite is
  `<owningRoomId>@r<itemIndex>@p<dumpPathId>`; two DIFFERENT rooms sharing
  uid 0 inside ONE dump contribute equal itemIndex and equal pathId, so
  every fallback leg collides and the chain ends — exactly the "silent
  merge" the law forbids, now at scale.
- Joins: **20,263 / 22,878** room-family placements have an `owningRoomId`
  that matches NOTHING in `rooms.jsonl` (rooms demote with
  `@r<recordIndex>`, placements with `@r<itemIndex>` — the two sides can
  never meet even where both demoted); **140 / 4,082** `landscape_layers`
  rows fail to join `plots.jsonl` keys (45 composited plots, layer rows
  keep raw ints). The planner substrate's primary relations are broken
  with no ledger naming it — the `identity-collisions` absence row records
  only the 1,932 INITIAL groups, not the residual duplicates or the broken
  references.

**Why the gates missed it:** the fixture gives every room a distinct uid,
so the demotion path stays cold hostless; no client-gated leg asserts
post-demotion uniqueness or placement→room / layers→plots joins.

**Contract hooks violated:** M2 identity law ("Uniqueness asserted under
the family's own key … never a silent merge") — the assertion simply does
not exist post-demotion; Principle one (relations ARE the database); hard
law 3 in spirit (the breakage is unnamed anywhere).

**Fix direction:** include `source.roomIndex` (already carried on every
room-family row and simply unused by the demotion) in the placement
collision key/composite; RE-ASSERT uniqueness after demotion and exit 1
loudly if any group still collides; propagate room/plot composites into
referencing columns (`owningRoomId`, `plotActivation.plotUniqueId`,
`layers.roomRecordId/plotUniqueId`) — or emit absence rows naming each
broken join class with sizes.

### F2 — MAJOR — the F6/AC11 "ONE mechanically pinned detection rule" is not mechanical: the audit ships a divergent second implementation

**Location:** `tests/_mapslib.py::gated_relation_violation` (1195) vs
`tools/maps_util.py::DoorGate.violation` / `door_gate_violation`
(459–561).

**Evidence:** the reconciliation commit added
`maps_util.door_gate_violation` explicitly "exposed for audit reuse" —
`_mapslib` never imports it. Its local rule differs operatively:
(i) ref-field detection by casefolded SUBSTRING tokens vs the stage's
exact-key intersection; (ii) the value-resolution leg scans the whole row
INCLUDING `source` (the stage excludes `source`); (iii) the containment
exception additionally requires `not named_room`. The AC11 post-hoc audit
also runs only over the FIXTURE tree (`test_stage7_maps.py` ~1400), never
the committed real tree. Latent today (zero gated rows exist), but Rev 3
F6 pins mechanism-level sharing ("shared verbatim … the SAME rule"), and
the divergence class — two detectors drifting while both docstrings claim
verbatim parity — is precisely what the pin exists to prevent.

### F3 — MAJOR — `analyze_doors` fabricates provenance for manifest-absent dumps and never raises the promised problem

**Location:** `tools/stage7_maps.py:1803–1812` (`_dir_fallback_bundle`),
used at 1700–1704.

**Evidence:** when a `TPC.ItemValidator_Door` dump is absent from
`export-manifest.jsonl`, the stage substitutes
`<family-dir>_assets_all.bundle` + a filename-stemmed pathId into
`source.bundle`. The docstring states "the missing-manifest problem is
raised by callers" — no caller appends a `problems` entry, so the row
ships with invented provenance and the run can stay green. Every sibling
walk does the opposite (append problem + skip). Invention-law breach on a
provenance leaf; latent on this corpus (all 54 dumps are manifested).

### F4 — MINOR — derived level fields ship without their pinned method stamps

`campaignPart` / `assetAddress` / `assetNameStem` are emitted bare; M2
pins `inferred:true` + `method:"address-path-segment"` /
`method:"container-index-reverse"` (restated in arbiter F14's fix shape).
Real `levels.jsonl` row keys carry neither. Schema-sketch omission is a
spec-side nit, but the build can carry the stamps today at zero risk.

### F5 — MINOR — crash-class failures bypass the failure log

(`json.JSONDecodeError`) or OSError aborts via traceback with NO run/failure
section, while M8 pins "failing runs append too — piece-1 Revision 4 rule".

### F6 — MINOR — ungated optional inputs degrade silently

`locales/locale-matrix.json` (M6 `locales[]`) and `media-catalogue.jsonl`
(M7 `mediaCatalogueClasses`) are consumed but absent from
`check_inputs`/`UPSTREAMS["maps"]`; absence yields empty projections with
no absence row and no runner pre-check — contrary to the absence-ledger
law's "never silence".

### F7 — MINOR — duplicated/dead logic invites helper↔behavior drift

`mu.demote_identity_collisions` and `mu.terrain_decode_status` are
test-exercised but UNUSED by the stage, which carries inline
reimplementations (`_demote`, `build_terrain_decode`) — the tested helper
and shipped logic can diverge unnoticed (they already differ in shape).
`mu.door_gate_violation` is unused anywhere (see F2); `seen_names` is
write-only; `axis_counts["plots"]` is computed and never printed.

### F8 — MINOR — misleading reason label for degenerate PPtrs

`_resolve_placement` returns bare `{"status":"unresolved"}` when
`pathId` is None; `finalize_and_report` then stamps the default reason
"cross-file target carries no indexed definition dump" — the wrong class
for a pathId-less PPtr. None observed on this corpus (latent).
