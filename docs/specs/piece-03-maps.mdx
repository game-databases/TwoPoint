### 1.1 Hard law (binding, restated from the ruling)

1. **R1 — dual-purpose geometry.** Authored cartography (path D,
   scout-001 §5) remains the PUBLIC `/map` skin. The scenario-derived
   footprints shipped by this piece are the **planner substrate** (the
   campus planner lays out real shapes on real grids) and the
   **registration/calibration layer** beneath that cartography. Both
   uses consume the same artifacts; neither justifies inventing data
   the client does not ship.
2. **No invented coordinates anywhere.** Every coordinate, bound,
   dimension, and rotation in every emitted row is copied verbatim from
   a harvested dump, or sits under a `derived` block carrying its
   `method` (a stated, deterministic transform over verbatim inputs).
   No rounding, no unit conversion, no axis swizzle, no "helpful"
   centering. Floats serialize by shortest-round-trip repr (Python
   `json.dumps` default) — never formatted or truncated.
3. **Absence ledgers name themselves.** Anything this piece cannot
   derive (door room-instance graph, terrain value legend, scene
   Transforms, media bytes) lands in a named artifact with `status`,
   `reason`, and `unblock` — never silence, never prose-only.
4. **R5 — axis-open schemas.** No campus list, DLC enum, or level-name
   whitelist is baked into any schema, validator, or test. Content-axis
   vocabulary stays the piece-1 enum `base | dlc-space | dlc-ghost`
   wherever an axis value is emitted, and every consumer path must
   accept an unseen axis value (Medical School, QUESTION-QUEUE #3, is
   modeled as roster-scoped fact, upgradable — never a permanent
   invariant of absence).
5. **Single-writer discipline.** This stage writes ONLY under
   `extracted/maps/` plus its EXTRACTION-LOG run section. It never
   writes under `extracted/relinks/`, `extracted/stubs/`, or any
   earlier stage's paths (it *reads* the relink bridges and registry).
