## 1. Goal

ONE additive entrypoint stage turns the verified locale inventory into
the proof artifacts extraction-doctrine Principle two demands —
completeness is PROVEN from primary artifacts, never claimed:

- New stage id **`locale-proof`**, script `tools/stage7_locale_proof.py`,
  registered ADDITIVELY in `tools/tpc_common.py::STAGES` AFTER `relink`
  (eight stages total). Every existing stage byte-behaves identically;
  the only cross-stage change is the ownership amendment of §5 (one
  file changes writer).
- **Purely derived stage:** it opens NO bundles and needs NO game dir.
  Its entire upstream set is committed `extracted/` artifacts (§4
  Inputs). Consequences: it runs hostless on the real corpus, the media
  carve-out guard cannot regress, and the fixture tree covers it without
  synthetic Unity bytes.
- **Emission root `extracted/locales/proof/`.** Justification: the
  artifacts audit and extend the stage-4 locale domain, so they sit
  beside the tables they prove (`extracted/locales/`); dropping seven
  new files into `relinks/` would muddy piece-2 §4's frozen per-file
  ownership map. THE ONE EXCEPTION is
  `extracted/relinks/locale_availability.jsonl`, which is regenerated AT
  ITS ARCHITECTURE-CANONICAL PATH because
  [localization-architecture.md §5.4](../../_foundation/localization-architecture.md)
  names that path verbatim as "the single source for the §2 link row,
  per-locale sitemaps, and coverage stats" — leaving it an empty 0-byte
  file is exactly scout gap **G1**. See §5.
- The five proof targets, mapped from the report:
  1. **Kind×locale coverage matrix** (report §2) — key-plane census +
     entity-plane per-kind rates + per-key hole enumerations +
     identity-to-pivot table.
  2. **`locale_availability.jsonl` regeneration** (report §5/G1) —
     deterministic rebuild from `entity_locale.jsonl` + the 13 tables;
     row counts derivable by the report §2.2 math; byte-stable; hashed.
  3. **Fallback law artifact** (report §4) — base overlay = pure master
     registry; named bundles self-contained; runtime fallback ORDER
     marked unprovable with the declarations cited; site consumes
     omit-or-declared-filler semantics (§5.5).
  4. **Site-UI namespace split** (report §5) — game-data coverage vs
     site-chrome ×13 (zero client coverage), emitting the gap manifest
     the W-D-polish lane #22 i18n scaffolding consumes.
  5. **Term-registry completeness** (report §3) — orphans both
     directions, status split, registry↔matrix diff 0, miss ledger.

Everything else — page-per-locale rendering, chrome authoring, sitemap
generation, course alias measurement — stays out (§8 Non-goals).

`entity_locale.jsonl` + the 13 tables (report §5/G1 unblock; §2.2 math).

                     "ru","tr","zh-Hans","zh-Hant"],

- Membership rules (pinned): `availableLocales` = ≥1 joined term with
  NON-EMPTY text in that locale (the §2 link-row membership rule;
  scout Q2 recommendation ADOPTED — presence counts, identity does not
  disqualify, and the identity residue is surfaced per-row via
  `identityToPivotLocales` + per-cell rates in L2, so flipping the
  policy later touches one rule, not the schema). `partialLocales` =
  some but not all joined terms present. `namedLocales` = ≥1 name-role
  term non-empty. `fieldPresence` = locale → fieldPaths with non-empty
  text (subset relationship asserted). `axes` inherited from stub rows'
  `axes` when present, omitted when absent (piece-2 R2 rule).
