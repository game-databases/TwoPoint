**Locations:** V-I9 expected cell ("`locale_availability.jsonl` →
stage5 only"); V-S10 ("`relinks/` holds ONLY the owned file set"); §2

reviewer validated Q3 against piece-02 §7 and never opened piece-07.

- *locale-proof first (the canonical order):* V-I9's illustrated map
  names a writer that no longer exists — the grep leg finds the
  locale-proof script as sole writer and the map says stage 5 ⇒ V-I9
  FAILS at introduction, a fourth red against AC2's "no other validator
  may be red"; V-S10's owned set likewise flags the regenerated file
  pair as strays. An implementer must silently rewrite the map — the
  exact unauthorized-side-picking F2 eliminated.
- *contracts first:* today's map is true, but when piece-07 lands, ITS
  routed doc deltas (piece-1 note, piece-2 §4/AC3) do not mention
  piece-05's `pins.pathOwner` or owned set — the move reaches pins.json
  with no routed owner, and the next contracts run goes red orphaned.

**Fix shape (mechanical; no fact-base change):**

   exactly ONE writer at any moment; `pins.pathOwner` names the current
   canonical writer per the pack's stage registry — stage 5 for
