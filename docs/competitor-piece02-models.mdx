## Application contract

For each source that is to count, the relink pass must:

1. enumerate its entity kinds and relationship families;
2. normalize labels to stable internal identities without replacing game IDs;
3. compare candidates with hard, logic-derived, and existing inferred client
   relations;
4. emit a new/strengthened relation, a targeted missing-pair probe, or a
   measured zero-delta result;
5. write one source-level application record;
6. regenerate the machine matrix,
   [`../extracted/RELATIONS.md`](../extracted/RELATIONS.md), and PROOF from the
   same run.

Candidate overlays may use `method:"competitor-model:<source-id>"` in
repository evidence. Client-measured duplicates are recorded as comparisons,
not duplicated as a second truth plane.
