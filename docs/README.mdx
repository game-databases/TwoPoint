## Retained evidence and contracts

### Scout reports

`scout-report-*.mdx` files are dated measurements. They are retained because
piece specs and implementation decisions cite their probes. They never own
current status; where a scout value differs from current generated evidence,
the generated evidence and canonical documents win.

### Piece specifications

`specs/piece-*.mdx` are executable stage contracts and acceptance histories.
They are retained because tests and source comments bind to their named rules.
They do not own current product phase or supersede later network decisions.

### Rulings

`rulings/*.mdx` preserves accepted/refuted findings and implementation
adjudications. A later canonical document may summarize or supersede their
operational state without rewriting decision history.

### Competitor model note

`competitor-piece02-models.mdx` records the model schema used by stage 6. The
current acquired/applied count is owned by `../competitor-research.md`.

## Removed documentation

The following directories were confirmed as session transcripts rather than
durable authorities and are removed in this review:

- `reviews/`
- `verifications/`

All unresolved findings and material measured results from those documents are
consolidated in `review-history.mdx`, `current-stage.mdx`, PROOF,
VALIDATION-REPORT, and `missingdata.md`. Git history retains the original
verbatim transcripts.

No new BRD, PRD, plan, or research note is authored as HTML. New durable
documentation is MDX; harness-fixed root filenames remain Markdown where
required.
