# Documentation map — exhaustive ledger

This is the manual ledger of every curated Markdown/MDX document retained in
the repository. It is documentation, not a checker or test. The current set is
**69** files: the previous 68 plus `extracted/media/MEDIA-EXPORT.md`.

## Complete read and cross-review

On 2026-09-04, every one of these **69 documents was read in full and reviewed
against the others**. The cross-review checked current phase and merge boundary,
client/build/DLC facts, 13 client locales versus 11 storefront-advertised
languages, stage order and single-writer ownership, the 10×10 relation matrix,
map identity findings, media policy, corpus publication timing, competitor
harvesting versus application, owner decisions, product scope, route plan, and
the game-derived visual direction. The newly added
`extracted/media/MEDIA-EXPORT.md` is included in that complete read.

Disposition vocabulary:

- **current authority** — owns live phase, policy, or product/visual contract;
- **current contract family** — pinned stage-0–6 human notes mirroring
  `pins.json`;
- **generated evidence** — measured outputs; latest run wins over older runs;
- **acquisition record** — factual source/provenance; not public content;
- **historical evidence** — dated scout; never current status;
- **historical executable contract** — named stage rules still bind code; does
  not own phase, publication timing, or permission to add tests;
- **historical ruling** — accepted/refuted findings stay; operational state may
  be summarized elsewhere;
- **test-suite note** — how the existing suite is used; does not add tests.

Where a dated file disagrees with a current authority or the latest generated
evidence, the current authority and latest evidence win. In-file historical
banners on scouts, piece specs, and rulings stay.
