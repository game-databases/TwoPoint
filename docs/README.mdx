## Retained evidence and contracts

### Scout reports

Eight `scout-report-*.mdx` files are dated measurements. Each file now carries
an in-file **Historical evidence** marker. They never own current status;
where a scout value differs from current generated evidence, the generated
evidence and current authorities win. Old publication, TestWriter, or
bootstrap language inside them is historical.

### Piece specifications

Eight `specs/piece-*.mdx` files are executable stage contracts and acceptance
histories. Each file now carries an in-file **Historical executable contract**
marker. Named rules remain binding for existing code. They do not own current
product phase, corpus-publication timing, or permission to add tests.

### Rulings

Twelve `rulings/*.mdx` files preserve accepted/refuted findings and
implementation adjudications. Each file now carries an in-file **Historical
ruling** marker. A current authority may summarize or supersede their
operational state without rewriting decision history.

### Contract notes

`../contracts/counter-units.mdx`, `../contracts/ledger-map.mdx`, and the eight
`../contracts/families/*.mdx` files document the currently pinned contract
families. Later-stage executable detail remains in the piece specifications
until promoted into `contracts/pins.json`.

### Source provenance

`../data/sources/competitor/*/PROVENANCE.md` records the three current
competitor-source outcomes. These are acquisition records, not public content
or current product status.

### Competitor model note

`competitor-piece02-models.mdx` records the model schema used by stage 6. The
current acquired/applied count is owned by `../competitor-research.md`.

## Removed documentation

The following directories were confirmed as session transcripts rather than
durable authorities and are removed:

- `reviews/`
- `verifications/`

All unresolved findings and material measured results from those documents are
consolidated in `review-history.mdx`, `current-stage.mdx`, PROOF,
VALIDATION-REPORT, and `../missingdata.md`. Git history retains the original
verbatim transcripts.

No new BRD, PRD, plan, or research note is authored as HTML. New durable
documentation is MDX; harness-fixed root filenames remain Markdown where
required.
