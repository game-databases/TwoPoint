## 7. Reference-site bar

What the TPC site must match or beat, from `database-visuals-examples/`
(enka.network, wikily.gg, new-world.guide; metaforge/questlog/bray.tech
blocked = findings):

1. **Hover = definition or join, on every data-bearing field** (Enka):
   one icon vocabulary across the page so a hover lights every instance
   of that stat/relation bidirectionally — course requirement ↔ room
   item ↔ student grade must highlight as one join, not tooltip prose.
2. **State is always in the URL + title + meta description** (beats
   Enka's measured defect: selected character absent from URL/title,
   empty `meta description`; adopt NWG's module hashes `#map`,
   `#use_in_quest`). One entity, one forever-URL per FRAMEWORK §2.7.
3. **Every mentioned entity is an `<a>`** (beat Enka: weapon/set names
   are pictures, not links): the relink graph renders as crawlable HTML
   with aggressive internal linking per `site-sections.md` — this is the
   SEO organism Enka lacks.
4. **Honest empty states + fractions-vs-max**: designed empty wells for
   missing slots, roll-quality fractions with totals row — TPC analog:
   locale strings present/absent per language shown as data, never
   apology copy.
5. **Owned map module on every location-bearing campus/plot page +
   typed language control replaced by route-coded locale URLs**
   (`/de/`, `/pt-br/`…); MapGenie is placement/pin-density reference
   only; colour-keyed object identity (Wikily's facet chips with counts)
   carries the DLC/locale dimension filters.
