this file before merge. Replace `PENDING` with the command, observed result,
artifact path, and final decision; do not leave results in chat.

## Review pass 2 — independent final review

**Status:** PENDING

Required checks:

- no unresolved review thread;

- no required documentation missing;
- no confirmed-irrelevant transcript documentation restored;
- no `site/` tree while the data gate is red;
- no GitHub Actions workflow added or dispatched;

- no secret/key/client binary;

- pull request non-draft and GitHub reports mergeable;
- combined commit status contains no failure.

Record final head SHA, diff line count, mergeability, commit status, and the
reviewer's `APPROVE`/`REQUEST_CHANGES` decision here.

## Cleanup responsibility

The final reviewing agent owns this cleanup:

1. replace all `PENDING` markers with empirical results;
2. remove instructions that have become irrelevant after successful checks;
3. retain a concise record of commands, counts, and why the chosen solution
   won;
4. update the PR description to the same final truth;
5. submit the second review on the final head.

A merge with `PENDING` still present means this handoff was not executed.
