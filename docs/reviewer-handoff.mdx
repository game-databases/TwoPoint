## Repository review pass 2

The second review is a PR review submission anchored to the final head; no
repository edit follows it. It independently checks:

- no unresolved review thread;
- no stale canonical status statement;
- no required documentation missing;
- no confirmed-irrelevant transcript restored or linked;
- no `site/` tree while the data gate is red;
- no GitHub Actions workflow added, changed, or dispatched;
- total diff at most 30,000 added+deleted lines;
- no secret, credential, client binary, or opaque large blob;
- branch based on current `main`;
- PR open, non-draft, and GitHub mergeable;
- combined commit status has no failure.

The review body records final head SHA, diff counts, mergeability, combined
status, and its final repository-level verdict.
