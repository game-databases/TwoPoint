interactive map, campus/course planner builder, guides, news, calculators,

(enka feel · wikily language · new-world.guide structure), judged by harsh
side-by-side visual critics. Forward-designed as the first entry of a
**Two Point game picker**: each future Two Point game gets its own theme
and soul; the house style family is shared.

## Binding gates

- Data completeness **before frontend** (AGENTS.md rule 8) — extraction,
  relinking, derived geometry, logic reconstruction all finish first.
- Owned map differentiator: dedicated `/map` + map module on every
  location-bearing page; third-party embeds banned.
- All locales the client ships ([FRAMEWORK §2.4](../FRAMEWORK.md)) —
  verified against the client, not marketing.
- Orchestrator never codes; every piece goes through
  Scout→Documentator→Reviewer→Arbiter → CodeWriter+TestWriter →
  CodeReviewer+TestReviewer → Arbiter → fix loops, fresh agents each round;
  visual critics judge the running site, not summaries.
