# Dataset contract layer

`contracts/` is the tracked, machine-checkable promise over the pipeline's
emitted artifacts for client buildId `20226581`.

## Contents

| Path | Role |
|---|---|
| `pins.json` | canonical constants, enums, ownership, reconciliation, and scope pins |
| `red-registry.json` | known failing validators that must remain loud |
| `counter-units.mdx` | unit and transform vocabulary |
| `ledger-map.mdx` | ledger ownership and exit-code contribution |
| `families/*.mdx` | human-readable family contracts mirroring `pins.json` slices |

## Ownership

The thirteen stages each own disjoint output families. The current
locale-availability owner is stage 9 `locale-proof`; stage 5 no longer owns or
recreates that file. Stage 10 is a read-only validator. Pipeline stamps and
the append-only extraction log are machine-plane evidence, not public content.

## Commands

```bash
python tools/stage10_check_contracts.py
python tools/stage10_check_contracts.py --scan-catalog
make contracts
```

Exit codes:

- `0`: every validator is green;
- `1`: unexpected contract failure or stale pin;
- `2`: completed with only explicitly registered expected-red findings;
- `3`: required inputs are unavailable.

An expected-red row is not a waiver. Its registry entry names the owner and the
change that removes it.

## Re-pinning

After a client build change:

1. run the full pipeline from the reviewed source tree;
2. inspect every stale pin;
3. update `pins.json` and the corresponding family document together;
4. fix derived reconciliation failures in the emitter, never by changing the
   identity to fit broken output;
5. rerun the contract suite and regenerate proof evidence.

## Publication

Generated artifacts are no longer categorically excluded from Git. Every file
below the current repository cap is committed, subject to the approximately
1 GB per-commit ceiling. Larger artifacts remain in an explicit local-large
staging area and are listed in PROOF with exact paths and sizes. The contract
history and the artifacts it describes must not contradict each other.
