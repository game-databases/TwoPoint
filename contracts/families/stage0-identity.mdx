# Stage 0 — client identity + bundle roster

`identity.json` carries exactly 13 top-level keys and anchors the pin
build scope; `bundle-roster.jsonl` is one row per corpus bundle under the
frozen six-key envelope, sorted by `relpath`. Domain splits are pinned
constants (V-S2): movement of any of them is a reviewable re-pin, never
drift. V-R7 re-enumerates the three corpus dirs against this roster on
any machine holding the game dir.
