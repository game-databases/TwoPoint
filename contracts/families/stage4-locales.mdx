# Stage 4 — locales, base overlay, reports

Per-locale run-section `rows` are EMISSION EVENTS including duplicate-key
overwrites; each file emits one line per DISTINCT key. The difference
(+5/locale today, same five duplicated Term keys everywhere) is real
data — a naive `rows == wc -l` pin would itself be the bug, which is why
the mixed-unit identity is licensed only through the
`events-minus-distinct-lines` transform (V-U3 gate). RED-2 makes
`duplicateKeysOverwritten` printed AND persisted so the units close on
paper.
