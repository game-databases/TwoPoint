# Two Point Campus — missing data and unresolved proof

This is the single human ledger for data that is absent, unresolved, partially
modeled, or not yet proven through to the eventual site. It does not authorize
invented substitutions.

## Release-blocking

### MAP-1 — placement identity collisions

The latest corpus review measured 1,775 placement identity collision groups
after the current demotion pass. Composite room IDs do not propagate
consistently into placements and landscape layers.

**Unblock:** include stable source record indices in composite identities,
propagate the final identities to every referencing row, assert zero duplicate
family keys after demotion, and prove placement→room and layer→plot closure on
the real corpus.

### MAP-2 — map test teeth

Emitter-path door gating, dual ID-space sweep results, and closed generation
vocabulary were deletable without failing the reviewed test selection.

**Unblock:** repair the implementation, then re-prove each behavior with the
existing suite, a disposable working tree that deletes that behavior, and a
real-corpus run. Do not add tests to this pack for that review.

### MEDIA-1 — all-image coverage

The web entity export is not a complete reconciliation of 6,789 Sprites, 47
SpriteAtlases, and 7,977 Texture2D records. Tracked subset evidence
(2,222 WebP, 29 PNG twins, 2,151/2,158 joins, seven named absences) lives in
[`extracted/media/MEDIA-EXPORT.md`](extracted/media/MEDIA-EXPORT.md) and does
not claim all-image completion.

**Unblock:** source-object→decoded-output manifest with exclusions only where
the current policy explicitly permits them.

### MEDIA-2 — eligible models

The catalogue contains 19,249 Mesh records. No current proof classifies every
mesh by location/non-location and size or exports every mandatory non-location
model under 50 MB. The 50–200 MB band is very likely empty on the parent
census, but withheld containers make that unproven.

**Unblock:** classify every mesh, decode every mandatory model, confirm every
higher-band model or prove the band empty, hash, publish/stage, and reconcile.

### MEDIA-3 — animation disposition

The catalogue records 7,985 AnimationClip objects. The current network ruling
leaves animations as an owner choice after complete inventory.

**Unblock:** inventory every animation and apply the Q3 retain/offload/drop
decision without silently discarding any source row.

### REL-1 — competitor application floor

Two independent readable models exist, one source is walled, and the latest
application count is zero.

**Unblock:** acquire a third independent model and record three applied
comparisons/deltas.

### PUB-1 — corpus publication

Historical ignore rules hide the generated corpus from GitHub. The repository
does not yet prove every under-cap file was committed or every larger artifact
was staged for production.

**Unblock:** size/hash census on `NE8K` and Mac; commit, shard, or explicitly
stage every file under the current policy.

### PROOF-1 — reviewed-tree reproduction

Tracked artifacts may have been produced by a host checkout that drifted from
the latest committed source.

**Unblock:** relay reviewed scripts, hash-compare, rerun, and regenerate all
proof documents from that exact tree.

## Logic gaps

assessment score is not recovered.

**Unblock:** scoped native analysis guided by the structural dump; emit no
number until recovered.

### LOGIC-2 — student core-11 decay

The client corpus has no recovered carrier for the eleven student core
attribute decay values.

**Unblock:** native analysis or controlled save-state/time-delta measurement.

## Product/site gap

The public site, routes, localized chrome, SEO/AEO artifacts, accounts/UGC,
tools, map UI, Skill, and MCP server do not exist. This is an intentional
downstream gap while the data gate is closed, not permission to ship a generic
placeholder.

The future implementation contracts are `docs/site-plan.mdx` (product, routes,
launch order) and `docs/design-direction.mdx` (visual bar). Neither authorizes
a generic placeholder.
